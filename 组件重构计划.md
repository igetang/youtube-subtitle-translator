# 组件重构计划

## 🎯 目标：消除重复调用，实现单一职责

### 问题现状
- UIManager 承担6个职责：UI渲染 + 状态管理 + 消息通信 + 事件处理 + 生命周期 + 业务逻辑
- ControlPanel 承担5个职责：双重状态管理 + 消息通信 + 事件监听 + 数据处理 + 业务逻辑
- 每个组件独立调用 `getRuntimeState` 和 `getUserPreferences`
- 重复调用源头：组件设计混乱，不是性能问题

## 🚀 解决方案：统一初始化 + 被动接收

### 核心原则
1. **组件不主动获取状态** - 只被动接收
2. **协调器统一调用** - 一次获取，分发给所有组件  
3. **单向数据流** - 协调器 → 组件，避免循环调用
4. **职责单一** - 每个类只做一件事

## 📋 重构步骤

### 第1步：创建ContentScript协调器
```typescript
// src/content-scripts/content-script-coordinator.ts
class ContentScriptCoordinator {
  private uiRenderer: UIRenderer;
  private stateManager: StateManager;
  private eventHandler: EventHandler;
  
  async initialize() {
    // 1. 一次性获取所有状态
    const [runtimeState, userPrefs, uiState] = await Promise.all([
      this.getState('runtime'),
      this.getState('preferences'), 
      this.getState('ui')
    ]);
    
    // 2. 初始化各个单一职责组件
    this.uiRenderer = new UIRenderer();
    this.stateManager = new StateManager();
    this.eventHandler = new EventHandler();
    
    // 3. 将状态分发给组件（被动接收）
    this.uiRenderer.initialize(uiState, runtimeState);
    this.stateManager.initialize(runtimeState, userPrefs);
    this.eventHandler.initialize();
    
    // 4. 设置组件间通信
    this.setupCommunication();
  }
  
  private async getState(type: string) {
    return chrome.runtime.sendMessage({ type: `get${type}State` });
  }
  
  // 处理用户行为事件
  handleUserAction(action: string, data: any) {
    switch(action) {
      case 'buttonClick':
        this.stateManager.updateState(data);
        break;
      case 'stateChange':
        this.uiRenderer.update(data);
        break;
    }
  }
}
```

### 第2步：重构UIManager → UIRenderer
```typescript
// src/shared/components/ui-renderer.ts
class UIRenderer {
  // 职责：纯UI渲染，不获取状态
  initialize(uiState: UIState, runtimeState: RuntimeState) {
    this.render(uiState);
    this.updateButtonStates(runtimeState);
  }
  
  // 只做UI创建
  private render(uiState: UIState) {
    this.createTranslateButton();
    this.createSettingsButton();  
    this.createTooltip();
  }
  
  // 只做UI更新
  update(changes: Partial<UIState>) {
    if (changes.translateActive !== undefined) {
      this.updateTranslateButton(changes.translateActive);
    }
  }
  
  // 不处理业务逻辑，只上报事件
  private onButtonClick(buttonType: string) {
    this.coordinator.handleUserAction('buttonClick', { buttonType });
  }
}
```

### 第3步：重构ControlPanel → StateManager  
```typescript
// src/shared/components/state-manager.ts
class StateManager {
  private runtimeState: RuntimeState;
  private userPreferences: UserPreferences;
  
  // 职责：纯状态管理，不发送消息
  initialize(runtimeState: RuntimeState, userPrefs: UserPreferences) {
    this.runtimeState = runtimeState;
    this.userPreferences = userPrefs;
  }
  
  // 只做状态更新
  async updateState(key: string, value: any) {
    const result = await chrome.runtime.sendMessage({
      type: 'setRuntimeState',
      data: { key, value }
    });
    
    if (result.success) {
      this.runtimeState[key] = value;
      this.notifyStateChange(key, value);
    }
  }
  
  // 只做状态变化通知
  private notifyStateChange(key: string, value: any) {
    this.coordinator.handleUserAction('stateChange', { key, value });
  }
}
```

### 第4步：创建EventHandler
```typescript
// src/shared/components/event-handler.ts  
class EventHandler {
  // 职责：纯事件处理，不处理业务逻辑
  initialize() {
    this.setupPageNavigation();
    this.setupTabSwitch();
    this.setupVisibilityChange();
  }
  
  private setupTabSwitch() {
    document.addEventListener('visibilitychange', () => {
      if (document.visibilityState === 'visible') {
        // 不直接处理，只通知协调器
        this.coordinator.handleUserAction('pageVisible', {
          timestamp: Date.now()
        });
      }
    });
  }
}
```

### 第5步：修改content-script.ts入口
```typescript
// src/content-scripts/content-script.ts
import { ContentScriptCoordinator } from './content-script-coordinator';

let coordinator: ContentScriptCoordinator;

// 统一初始化入口
async function initializeContentScript() {
  coordinator = new ContentScriptCoordinator();
  await coordinator.initialize();
  console.log('[content-script] ✅ 统一初始化完成');
}

// 页面加载时调用
initializeContentScript();
```

## 🎯 重构效果

### Before（问题状态）
```
UIManager.initialize() → getRuntimeState() 
UIManager.initialize() → getUserPreferences()
ControlPanel.initialize() → getRuntimeState()  
ControlPanel.initialize() → getUserPreferences()
// 4次重复调用
```

### After（重构后）
```
ContentScriptCoordinator.initialize() → 一次批量获取所有状态
├─ UIRenderer.initialize(状态) ← 被动接收
├─ StateManager.initialize(状态) ← 被动接收  
└─ EventHandler.initialize() ← 无状态依赖
// 1次调用，0次重复
```

## 📚 核心理念

**"从根本上消除重复调用的可能性，而不是用去重机制掩盖设计问题"**

- ✅ 组件单一职责
- ✅ 统一初始化入口  
- ✅ 被动接收状态
- ✅ 事件上报机制
- ❌ 拒绝去重缓存等复杂机制
