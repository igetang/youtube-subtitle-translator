# 快速验证指南 - MessageBus迁移后验证

## 🎯 验证目标
验证MessageBus迁移完成后，所有功能正常工作，特别是UI按钮显示问题已修复。

## 🔧 修复内容
**问题1**：消息格式不匹配
- main-world.ts发送的`MAIN_WORLD_READY`消息格式与content-script.ts期望的`main-world:ready`不匹配

**修复1**：在`handleUIStateUpdate()`中同时支持两种消息格式：
```typescript
// 修复前
if (data.eventType === 'main-world:ready') {

// 修复后  
if (data.eventType === 'main-world:ready' || data.type === 'MAIN_WORLD_READY') {
```

**问题2**：MessageBus架构错误（根本问题）
- setupMessageHandlers()中通过`messageBus.sendMessage()`发送消息到background
- 但`handleUIStateUpdate`回调在当前content-script中，无法被触发

**修复2**：直接调用回调函数：
```typescript
// 修复前（错误的架构）
messageBus.sendMessage({
  type: MessageType.UI_STATE_UPDATE,
  data: { ... }
});

// 修复后（正确的架构）
handleUIStateUpdate({ 
  type, 
  payload,
  source,
  eventType,
  eventData
});
```
