# YouTube字幕翻译助手

## 项目概述

这是一个Chrome扩展，为YouTube视频提供实时字幕翻译功能。它允许用户将任何YouTube字幕轨道实时翻译为目标语言，支持双语显示，并集成了多种免费翻译API。

## 主要功能

* **实时字幕翻译**：将YouTube视频字幕即时翻译为任何目标语言
* **智能语言选择**：
  * **ASR轨道识别**：源语言下拉菜单自动识别并标注"（自动生成）"的ASR字幕轨道
  * **语言族互斥**：目标语言选择智能排除同语言族选项（如源语言为英语时，禁用英语变种）
  * **轨道类型切换**：支持在手动字幕和自动生成字幕间无缝切换，自动触发翻译更新
* **多种翻译API支持**：
  * Google翻译（免费无需API密钥）
  * 有道翻译（对中文支持良好）
  * 微软/Bing翻译（翻译质量高）
  * OpenAI（需用户提供API密钥）
* **双语字幕显示**：支持原文+译文的双语显示和纯译文显示模式
* **友好的设置界面**：通过Chrome侧边栏提供直观的设置界面
* **智能缓存**：缓存翻译结果，提高性能并减少API调用
* **错误处理**：完善的错误处理和自动故障转移机制

## 使用方法

### 基本使用流程

1. **安装扩展**：按照上述安装方法完成扩展安装
2. **访问YouTube**：打开任意YouTube视频页面
3. **开启翻译**：
   - 视频播放器右下角会出现翻译按钮
   - 点击翻译按钮开启实时字幕翻译
4. **调整设置**：
   - 点击设置按钮打开侧边栏
   - 选择源语言和目标语言
     * **ASR轨道识别**：源语言列表中带"（自动生成）"标识的为AI自动生成字幕
     * **智能选择**：目标语言自动排除与源语言相同的语言族（避免英语翻英语等无意义操作）
     * **轨道切换**：可在手动字幕和自动字幕间切换，系统会自动更新翻译
   - 选择翻译API
   - 设置字幕显示模式（双语/仅目标语言）

### 翻译API选择指南

* **Google翻译**：免费、无需API密钥、翻译速度快，适合大多数用户
* **微软翻译**：翻译质量高，支持更多语言对，无需API密钥
* **OpenAI**：翻译质量最佳，需要用户提供自己的API密钥

### 常见问题

#### 没有翻译按钮？
- 确保视频有字幕轨道（自动生成或手动添加）
- 刷新页面重试
- 检查扩展是否正确安装并启用

#### 翻译不工作？
- 检查网络连接
- 尝试切换不同的翻译API
- 确认选择的源语言与视频字幕语言一致

#### 翻译速度慢？
- 优先使用Google翻译，速度最快
- 避免频繁切换语言设置
- 清除浏览器缓存后重试

#### API密钥错误？
- 检查OpenAI API密钥是否正确
- 确认API密钥有足够的额度
- 尝试重新输入API密钥

## 隐私说明

* 扩展只在用户主动开启翻译时发送字幕文本到翻译API
* 不收集用户个人信息
* 翻译设置和缓存数据仅存储在本地浏览器中
* 不向第三方服务发送用户数据（除选择的翻译API外）

## 支持的语言

扩展支持所有主流语言之间的翻译，包括但不限于：
- 中文（简体/繁体）
- 英语
- 日语
- 韩语
- 法语
- 德语
- 西班牙语
- 俄语
- 阿拉伯语
- 葡萄牙语

具体支持的语言对取决于选择的翻译API。
