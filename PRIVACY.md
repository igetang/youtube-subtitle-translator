# Privacy Policy / 隐私政策

**Last Updated / 最后更新：** 2025-11-16
**Version / 版本：** 1.0.0

---

## English

### Overview

YouTube Subtitle Translator ("the Extension") is committed to protecting your privacy. This privacy policy explains how we handle data when you use our Chrome extension.

### Data We DO NOT Collect

We **DO NOT** collect, store, or transmit:
- ❌ Personal identification information
- ❌ Browsing history
- ❌ Video watching records
- ❌ Any data to our servers (we don't have any servers)

### Data Stored Locally

The following data is stored **locally in your browser only**:

1. **User Preferences**
   - Language settings (source language, target language)
   - Translation service selection
   - Subtitle display preferences
   - Stored locally using Chrome's `storage.local` API
   - Never transmitted to external servers

2. **API Keys** (if you choose to use paid translation services)
   - Only stored locally in your browser
   - Never uploaded or shared
   - You can delete them at any time through the extension settings

3. **Translation Cache**
   - Cached translations for performance improvement
   - Stored locally only
   - Automatically managed with size limits

### Third-Party Services

To provide translation functionality, subtitle text is sent to your chosen translation service:

**Free Services (default):**
- Google Translate
- Microsoft Translator

**Optional Services (require API key):**
- DeepL
- OpenAI
- DeepSeek
- Google Gemini
- Alibaba Qwen

**Important Notes:**
- Subtitle text is sent to the translation service you select
- We do not collect, store, or analyze this translation data
- Each service has its own privacy policy (please refer to their official documentation)
- You choose which service to use

### Permissions Used

1. **storage** - Store user preferences and translation cache locally
2. **tabs** - Detect YouTube pages to enable translation features
3. **host_permissions** - Access YouTube pages and translation API endpoints

### Data Security

- All user data is stored locally in your browser
- API keys use Chrome's secure storage mechanism
- No data is uploaded to developer servers
- Extension code is open source and available for review

### Changes to This Policy

We may update this privacy policy from time to time. We will notify users of any changes by updating the "Last Updated" date.

### Contact

If you have questions about this privacy policy, please:
- Open an issue on GitHub: https://github.com/igetang/youtube-subtitle-translator/issues
- Review our source code: https://github.com/igetang/youtube-subtitle-translator

## 中文

### 概述

YouTube字幕翻译助手（"本扩展"）致力于保护您的隐私。本隐私政策说明我们如何处理您使用Chrome扩展时的数据。

### 我们不收集的数据

我们**不会**收集、存储或传输：
- ❌ 个人身份信息
- ❌ 浏览历史记录
- ❌ 视频观看记录
- ❌ 任何数据到开发者服务器（我们没有任何服务器）

### 本地存储的数据

以下数据**仅存储在您的浏览器本地**：

1. **用户设置**
   - 语言设置（源语言、目标语言）
   - 翻译服务选择
   - 字幕显示偏好
   - 使用Chrome的`storage.local` API本地存储
   - 永不传输到外部服务器

2. **API密钥**（如果您选择使用付费翻译服务）
   - 仅存储在您的浏览器本地
   - 永不上传或分享
   - 您可以随时通过扩展设置删除

3. **翻译缓存**
   - 缓存的翻译结果用于提升性能
   - 仅本地存储
   - 自动管理，有大小限制

### 第三方服务使用

为了提供翻译功能，字幕文本会发送到您选择的翻译服务：

**免费服务（默认）：**
- Google翻译
- 微软翻译

**可选服务（需要API密钥）：**
- DeepL
- OpenAI
- DeepSeek
- Google Gemini
- 阿里云通义千问

**重要说明：**
- 字幕内容会发送到您选择的翻译服务
- 我们不会额外收集、存储或分析这些翻译数据
- 各翻译服务有各自的隐私政策（请参考其官方说明）
- 您可以选择使用哪个服务

### 使用的权限

1. **storage** - 本地存储用户偏好和翻译缓存
2. **tabs** - 检测YouTube页面以启用翻译功能
3. **host_permissions** - 访问YouTube页面和翻译API端点

### 数据安全

- 所有用户数据仅保存在您的浏览器本地
- API密钥使用Chrome的安全存储机制
- 没有数据上传到开发者服务器
- 扩展代码开源，可供审查

### 政策更新

我们可能会不定期更新本隐私政策。任何更改都会通过更新"最后更新"日期来通知用户。

### 联系方式

如果您对本隐私政策有任何疑问，请：
- 在GitHub提交Issue：https://github.com/igetang/youtube-subtitle-translator/issues
- 查看我们的源代码：https://github.com/igetang/youtube-subtitle-translator
